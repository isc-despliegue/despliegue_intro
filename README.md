# UD0- Introducción al Módulo de Despliegue de plataformas de ejecución de contenedores
La documentación de esta unidad está disponible en formato markdown dentro del directorio **docs**.
Puedes levantar un container para visualizar la documentación utilizando el archivo de despliegue **docker-compose.yml** del repositorio. Para ello simplemente ejecuta desde la raíz:

```bash
docker compose up -d
```

Una vez levantado el container podrás acceder a él mediante el navegador web de tu sistema en la URL: [http://localhost:8000][def]

[def]: http://localhost:8000
