# Resumen del Módulo Profesional: Despliegue de Plataformas de Ejecución de Contenedores
A continuación se presenta de forma clara y sencilla los aspectos fundamentales del módulo profesional para que puedas comprender qué vas a estudiar, cuáles son tus objetivos y cómo se estructuran los contenidos de acuerdo al real decreto oficial.

---

## 1. Identificación del Módulo

*   **Código:** 5166.
*   **Denominación:** Despliegue de plataformas de ejecución de contenedores.
*   **Duración:** 120 horas.
*   **Equivalencia en Créditos ECTS:** 7 créditos.
*   **Curso de Especialización de referencia:** Este módulo forma parte del Curso de Especialización de Grado Superior en **Despliegue de productos software en contenedores** (que tiene una duración total de 630 horas y 38 créditos ECTS).

---

## 2. ¿De qué trata este módulo? (Visión General)
En el desarrollo de software moderno ya no es suficiente con programar una aplicación; también es necesario saber **dónde** y **cómo** se va a ejecutar de manera automática, segura y a gran escala. Hoy en día, el estándar de la industria consiste en empaquetar el software en contenedores virtuales. 

En este módulo aprenderás a **preparar, automatizar y vigilar la infraestructura tecnológica (los servidores y las redes) en la nube o en entornos locales donde se ejecutan estos contenedores**. Estudiarás desde la creación de redes virtuales privadas aisladas hasta la redacción de líneas de código para levantar servidores automáticamente y el despliegue de "orquestadores" (como Kubernetes) que aseguran que las aplicaciones estén siempre disponibles y funcionando.

---

## 3. Resultados de Aprendizaje (Objetivos Principales)

Al cursar este módulo, desarrollarás las capacidades necesarias para alcanzar los siguientes objetivos teóricos y prácticos:

1.  **Crear estructuras de recursos virtuales privadas:** Aprenderás a instalar hipervisores y configurar los recursos asociados a nubes virtuales privadas seguras, aplicando aislamiento de red para proteger los entornos informáticos de accesos no autorizados.
2.  **Gestionar accesos a la nube:** Utilizarás paneles gráficos (páginas web de proveedores cloud) e interfaces de línea de comandos (CLI) en terminales de texto para interactuar de forma ágil y segura con los servicios en ámbitos privados.
3.  **Escribir Infraestructura como Código (IaC):** Desarrollarás código capaz de automatizar el despliegue de almacenamiento, memoria y procesadores según las necesidades específicas de la aplicación.
4.  **Montar orquestadores y sistemas de monitorización:** Desplegarás plataformas que automatizan las tareas de los contenedores (orquestadores), configurarás flujos de trabajo automatizados (pipelines) y diseñarás paneles interactivos para vigilar indicadores clave de rendimiento (KPIs).

## 4. Estructura de Contenidos
El temario se organiza en **cuatro bloques temáticos, a modo de unidades didácticas** con un enfoque eminentemente práctico:

### Bloque 1: Entornos de Virtualización y Nubes Virtuales

*   **Hipervisores:** Instalación y configuración para la virtualización de sistemas informáticos, entendiendo sus límites y funciones.
*   **Diseño de VPC:** Creación de servidores virtuales utilizando la consola del hipervisor, asignando direccionamiento IP, servidores DNS y zonas de disponibilidad.
*   **Seguridad tecnológica de red:** Implementación de capas de seguridad digital y segmentación para garantizar el aislamiento de entornos y la separación de clientes.

### Bloque 2: Interfaces de Acceso a la gestión del Entorno

*   **Gestión por Interfaz Gráfica (GUI):** Conexión segura a través de navegadores web a plataformas de despliegue, personalizando aspectos visuales, idiomas y preferencias.
*   **Línea de Comandos (CLI):** Descarga, inicialización y administración segura de servicios mediante terminales locales o de servidores.
*   **Librerías de cliente:** Integración de librerías específicas según el lenguaje de programación utilizando gestores de dependencias.

### Bloque 3: Infraestructura como Código (IaC)

*   **Definición de requerimientos:** Selección óptima de recursos de hardware virtual (cómputo, almacenamiento y memoria) según las necesidades de la aplicación.
*   **Creación de plantillas IaC:** Escritura de código utilizando editores de texto para automatizar la construcción de la infraestructura de TI.
*   **Lanzamiento y auditoría:** Ejecución del código para desplegar los entornos y chequeo automático del cumplimiento de las políticas de seguridad digital.

### Bloque 4: Orquestación, Pipelines y Monitorización

*   **El Orquestador:** Selección, instalación y parametrización de herramientas de orquestación, regulando permisos, certificados y opciones de despliegue.
*   **Flujos automatizados (Pipelines):** Diseño de flujos de trabajo parametrizados para encadenar las fases de despliegue, controlando la secuencia lógica y el tratamiento de errores.
*   **Seguridad de mínimo privilegio:** Configuración de credenciales y accesos con los mínimos permisos estrictamente necesarios para ejecutar tareas.
*   **Gestión de métricas:** Selección de herramientas para la ingesta y visualización de datos, diseñando pantallas de métricas, sistemas de alarmas e indicadores clave de rendimiento (KPIs).
